# Руководство по первичной настройке и началу работы с новыми инструментами

При первом запуске программного обеспечения требуется активировать дополнительные возможности. Все действия по конфигурированию выполняются непосредственно в режиме «1С:Предприятие».

## 1. Настройка пользователей и прав доступа

Заведите учётную запись с правами «Администратор» (профиль «Администратор»).

Сформируйте пользователей с профилями: ВКМ_Бухгалтер, ВКМ_Кадровик-расчетчик, ВКМ_Специалист, ВКМ_Менеджер по обслуживанию. Для каждого выберите соответствующую роль из списка профилей.

## 2. Подсистема «Обслуживание клиентов»

В режиме администратора выполните сопряжение с Telegram-ботом.

Настройте фоновое регламентное задание для автоматической рассылки сообщений через бота.

Полученные в ходе настройки Telegram-бота данные (токен управления и идентификатор группы оповещения) занесите в константы:

ВКМ_ТокенУправленияТБотом

ВКМ_ИдентификаторГруппыОповещения

Подберите (или создайте) позиции номенклатуры с типом «Услуги», которые будут фигурировать в актах об оказании услуг. Рекомендованные наименования: «Абонентская плата» и «Работы специалиста». Сопоставьте их с константами:

ВКМ_НоменклатураАбонентскаяПлата

ВКМ_НоменклатураРаботыСпециалиста

## 3. Подготовка к первому запуску подсистемы «Обслуживание клиентов» (задача кадровика-расчетчика)

Подсистема работает со справочником «ВКМ_Сотрудники». Изначально он пуст.

Кадровик-расчетчик обязан внести в этот справочник фамилии всех сотрудников компании, а также заполнить регистр сведений «УсловияОплатыСотрудников» – поле «ПроцентОтВыполненныхРабот». Остальные реквизиты регистра (график работы и оклад) могут быть заполнены позже.

## 4. Подготовка к первому запуску подсистемы «Расчет зарплаты»

Заполните справочник «Графики работы». Примеры: «Пятидневка», «Шестидневка». Для учёта отпусков уже существует предопределённый элемент «Отпуск календарные дни».

Примените обработку «Заполнение графиков работ» для наполнения календаря выбранного графика. В поле «Выходные дни» перечислите цифры дней недели.

Кадровик-расчетчик обязан дополнить в регистре сведений «УсловияОплатыСотрудников» данные о графике работы и размере оклада для каждого сотрудника.

В разделе «Сервис» кадровик-расчетчик должен назначить для отпуска график, учитывающий все календарные дни.
